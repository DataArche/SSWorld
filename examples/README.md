# Examples

Three scenes an agent actually authored with this server, kept as their **hand-written sources,
generators and one screenshot each**.

| | what it shows | entry point |
|---|---|---|
| [GuanlanRoadTemplate0924](GuanlanRoadTemplate0924) | a real street network rebuilt from OpenStreetMap — roads, curbs, crossings, a river, parcels, houses, trees and lamps — by a reusable bbox-to-scene pipeline | `tools/road_template/new_site.ps1` |
| [SkylineGarden0919](SkylineGarden0919) | an original procedural city with traffic, signals, a train, park life, fountains and a day–night cycle with real point lights | `generate.py --detail` |
| [DaxiongHall0924](DaxiongHall0924) | a Chinese temple hall with double eaves, bracket sets, a marble terrace, incense smoke and a cinematic camera tour | `gen_scene.py` |

What is **not** here, on purpose: `scene.ir.json`, `scene.generated.mjs`, the generated `.ssdl`
components, glb meshes and textures, and (for Guanlan) the downloaded OSM data. Those are all build
products of the scripts in each example, so shipping them would be shipping the same information
twice. Each example is under 400 KB including its screenshot.

## Running one

```bash
# 1. let the server create the project (this writes the page shell)
#    via your agent:  ssworld_project_create { name: "DaxiongHall0924", longitude: ..., latitude: ... }
# 2. copy this directory's files over it
cp -r DaxiongHall0924/* ~/.ssworld/projects/DaxiongHall0924/
# 3. run the generator named in the project's own README
cd ~/.ssworld/projects/DaxiongHall0924 && python gen_scene.py
# 4. back in your agent:  ssworld_compile  then  ssworld_preview
```

Each project's `README.md` carries its anchor, exact reproduce steps, structure notes and honest
limits. GuanlanRoadTemplate0924 reuses the street-lamp model generated by SkylineGarden0919, so
generate that one first.

## Assets and licensing

Every mesh and texture in these three is generated by the scripts in the examples themselves — no
downloaded models or textures. The one external input is the Guanlan street network: geographic
data © OpenStreetMap contributors, available under the
[Open Database License](https://www.openstreetmap.org/copyright). It is fetched by the pipeline at
build time and is not bundled here.
