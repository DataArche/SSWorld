# 深圳北站 Shenzhen North Station

SSDL 0.3 程序化生成的深圳北站数字孪生场景（主站房 + 车场 + 南广场 + 周边），对照参考航拍图逐轮打磨。

## 怎么重建

```bash
python gen_tex.py        # 1. 生成 17 张程序化贴图到 assets/（含系统字体烧制的站名标识）
python gen_station.py    # 2. 生成 scene.ssdl
# 3. ssworld_compile / ssworld_preview 编译预览
```

两个脚本是唯一手写源；`scene.ssdl` 是产物，勿手改。两个脚本都确定性（重跑产物逐字节一致）。

| 岛式站台宽 | 12 m |

**B 类 —— 依公开资料整理，量级可信**

- 站台中心距取 22 m，车场南北净宽 220 m

**C 类 —— 从参考照片比例反推，非实测，用于视觉还原**
- 主站房屋面 **300 m（东西）× 236 m（南北）**，檐口 +38 m
- 两侧站台雨棚各 **75 m**（x=150→225）
- 南广场 **600 m 宽 × 250 m 深**（站房南立面 y=-118 → 南端步行桥 y=-368）

## 核心技术点

**1. 白色格栅屋面 = 程序化贴图 + HeightField 法线**
全场标志性元素。`gen_tex.py` 生成 `roof_grid.png`（16×16 格、每 4 格一道大分缝）与
配套 `roof_grid_n.png`，屋面用 **HeightField**（自带切线，法线图合法）。

**格栅尺度必须按成片分辨率反推**：初版用 2.5 m 格，成片里屋面约 520 px / 300 m = 1.7 px/m，
一格只有 4.3 px，而格缝仅占贴图 1/32 = **0.13 px 屏幕宽** —— 结果整片糊成白板。
改为 **4 m 格 + 2 px 格缝（= 0.25 m，实拍缝量级）**，`uvScale = 屋面尺寸 / 64`，
并把 `normalScale` 提到 1.7，格栅才读得出来。

**2. 站名标识 = 系统字体烧制贴图**
`Label` 组件缺字体会让整个场景加载失败，所以标识走贴图：`gen_tex.py` 用 PowerShell + System.Drawing
调 Microsoft YaHei / Arial 渲染 1536×512 的 `sign_main.png`，贴在 36×12 m 的倾斜檐口板上。

**3. 连续地形 + 高程落位**
北侧不是"一块平地 + 远处一座山"，而是一片从 y=620 连续升到山脊的 HeightField。
`terrain_h(x, y)` 在 Python 侧与 HeightField 用**同一个函数**求值，
所以街区、住宅塔、办公塔、树木的 z 都按地形高程落位，不会悬空或埋进坡里。

**4. 曝光锁定 = 可复现截图**
`autoExposureMinBrightness = autoExposureMaxBrightness = 1.0` 锁定白点，再用 `autoExposureBias`
调明暗。**实测**：同一 `source_digest` 连拍两次 `mean_luma` 122.677 / 122.669（差 0.006%）；
锁定前同样条件下会在 102 ↔ 128 之间漂移（差 25%）。

## 踩坑记录

1. **一个 target 只能挂一个 PrincipledMaterial**。辅助函数自动发了一次、我又手写一次，
   运行时报 `PrincipledMaterial.target already has a PrincipledMaterial`，**整个场景模块加载失败**
   （编译期不报）。现在 `src_box/src_loft` 支持 `emit_mat=False`，并加了重复检测。
2. **`Plane` 的贴图正面在 -Z 侧**。标识板按 `qx(64)` 放置时从南侧看是**镜像**的，
   必须转 `qx(-116)`（180°-64°）。几何光照看起来完全正常，只有带文字的贴图才暴露。
3. **自动曝光会让截图不可复现**（见上）。
4. 列表值不能跨行（`sections: [` 后换行直接 syntax_error）。
5. `SkyAtmosphere` 的 rayleigh/mie/skyLuminanceFactor 与太阳的 `useTemperature/temperature`
   会把整片天空染橙 —— 保持全默认，用 `lightColor` 调色。

## 截图工作流注意

`ssworld_capture_frame` 要求页面**可见且在前台**。每次跑完前台命令（pwsh）后 Chrome 会失去前台、
页面 rAF 被节流并断连，表现为 `page_timeout` / `visibility: hidden`。截图前需要重新激活窗口：

```powershell
# SetForegroundWindow + ShowWindow(SW_MAXIMIZE) 激活预览窗口，然后再截图
```
